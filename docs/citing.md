# Citing

If you use causalbase in a scientific publication, please cite:

```bibtex
@software{causalbase,
  author = {Torrijos, Pablo and G{\'a}mez, Jos{\'e} A. and Puerta, Jos{\'e} M.},
  title = {causalbase: Bayesian network structure learning and causal discovery},
  year = {2026},
  url = {https://github.com/ptorrijos99/causalbase}
}
```

The same information is in [`CITATION.cff`](https://github.com/ptorrijos99/causalbase/blob/main/CITATION.cff), which GitHub shows as "Cite this repository".

Please cite as well the method you use: Chickering (2002) for GES, Nazaret and Blei (2024) for XGES, Wienöbst, Henckel and Weichwald (2026) for FLOP, Silander and Myllymäki (2006) for the exact search by dynamic programming, and Cussens (2011) and Bartlett and Cussens (2017) for the integer program. The [README](https://github.com/ptorrijos99/causalbase#references) gives the full references.
